# map-extensions

قالب‌های فایل `.map`، `.msv` و `.sav` را گسترش می‌دهد.

این ماژول امکاناتی در اختیار سایر افزونه‌ها می‌گذارد. برای نمونه، Automarket تنظیمات خود را در فایل‌های ذخیرهٔ بازی ثبت می‌کند تا هنگام بارگذاری، تنظیمات تجارت همان بازی نیز بازیابی شوند.

این ماژول بر پایهٔ یافته‌های [sourcehold-maps](https://github.com/sourcehold/sourcehold-maps) ساخته شده است.

# map-extensions

Étend les formats de fichiers `.map`, `.msv` et `.sav`.

Ce module fournit des fonctions à d’autres extensions. Par exemple, Automarket enregistre sa configuration dans les sauvegardes afin de retrouver les réglages commerciaux propres à la partie lors de son chargement.

Le module s’appuie sur les connaissances de [sourcehold-maps](https://github.com/sourcehold/sourcehold-maps).

# map-extensions

Расширяет форматы файлов `.map`, `.msv` и `.sav`.

Модуль предоставляет функции другим расширениям. Например, Automarket записывает свои настройки в файлы сохранений, чтобы при загрузке восстанавливалась торговая конфигурация конкретной партии.

Модуль основан на сведениях из [sourcehold-maps](https://github.com/sourcehold/sourcehold-maps).

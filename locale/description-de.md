# map-extensions

Erweitert die Dateiformate `.map`, `.msv` und `.sav`.

Dieses Modul stellt Funktionen für andere Erweiterungen bereit. Beispielsweise speichert Automarket seine Einstellungen in Spielständen, damit beim Laden auch die Handelskonfiguration der jeweiligen Partie wiederhergestellt werden kann.

Das Modul basiert auf den Erkenntnissen von [sourcehold-maps](https://github.com/sourcehold/sourcehold-maps).

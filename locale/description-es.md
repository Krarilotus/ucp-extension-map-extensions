# map-extensions

Amplía los formatos de archivo `.map`, `.msv` y `.sav`.

Este módulo proporciona funciones a otras extensiones. Por ejemplo, Automarket guarda su configuración en las partidas guardadas, para recuperar los ajustes comerciales de esa partida al cargarla.

El módulo se basa en los conocimientos de [sourcehold-maps](https://github.com/sourcehold/sourcehold-maps).
